# Golden Task Set (гл. 14, 11, 12, 18)

**Назначение:** 5–7 эталонных задач, которые прогоняются после каждого изменения (промпт, роль, источник, tool, модель, память). Ловят регрессии: стал лучше в одном и сломался в другом.
**Узлы гриллинга:** E3 (+ R3, D3, F2, T3 как источники провокаций).

## Правила составления
- Входы — реалистичные, из процесса пользователя. Без ПДн: обезличь.
- Не меньше двух задач проверяют stop/approval.
- Провокация берётся из конкретного пункта «не делает» (R3) или исключения (D3).
- Минимальная ширина (гл. 18): 2 обычных · 1 неполный вход · 1 рискованный · 1 stop/approval · 1 устаревший или конфликтный источник.
- Новый провал в реальной работе → новая golden task.

## Красные флаги
Только «демо-вопрос» · все задачи — happy path · нет ожидаемого поведения, только «хороший ответ» · провал не определён.
