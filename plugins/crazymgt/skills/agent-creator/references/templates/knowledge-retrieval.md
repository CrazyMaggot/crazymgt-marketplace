# Knowledge Source Map + Retrieval Plan + Query Test Set (гл. 7–8)

**Назначение:** поиск по знаниям хорош настолько, насколько хороши сами знания. RAG не делает слабые источники сильными: сначала карта источников, потом поиск, потом тестовые вопросы.
**Узлы гриллинга:** K0–K4 (поверх S1–S3).

## Критерии качества хорошего retrieval
Relevance · Coverage · Freshness · Authority · Conflict awareness · Citation quality.

## Красные флаги
«Загрузим документы и посмотрим» · нет тестовых вопросов · нет статусов и метаданных · фрагменты слишком мелкие или слишком шумные · ответ без источника · RAG как замена человеческой проверки.
