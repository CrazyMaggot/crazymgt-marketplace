# Agent Role Card (гл. 4–5)

**Назначение:** описать агента как маленькую должность в процессе: зачем нужен, что делает, чего не делает, на что опирается, где останавливается, как отчитывается. Включает Capability Card (гл. 4): что исполнитель реально может.
**Узлы гриллинга:** R1–R7, P2, P3, P4, S1, T1, M0, A1, E1, F2.

## Шаблон

```markdown
# Agent Role Card — <агент>
Связано: 01, 03, 04, 05, 06, 07

1. **Название агента:** <по функции: «Агент первичного разбора заявок»>
2. **Назначение:** <зачем существует в процессе; без бизнес-чудес>
3. **Основная роль:** <кем является в процессе; что НЕ решает>
4. **Что входит в роль:**
   - …
5. **Что НЕ входит в роль:**
   - …
6. **Входные данные:** <что получает на вход>
7. **Источники истины:** <кратко; подробно — 03>
8. **Tools:** <инструмент — для чего — чего нельзя; подробно — 04>
9. **Memory rules:** <что можно и нельзя сохранять; «нет памяти» — тоже ответ>
10. **Approval rules:** <где агент останавливается и зовёт человека; подробно — 06>
11. **Output:** <основной продукт>
12. **Reporting:** что сделал · какие источники · где не хватило данных · что требует человека · следующий безопасный шаг
13. **Quality criteria:** <проверяемые признаки хорошей работы>
14. **Stop rule:** <когда обязан остановиться; подробно — 05>

## Capability (что исполнитель реально может в этой системе)
- Тип исполнителя: subagent | skill | orchestrator · модель: …
- Может сам: …
- Только черновик: …
- Только с approval: …
- Не может физически (нет tool или доступа): …
```

## Критерии качества (самопроверка гл. 5)
За 30 секунд понятно, зачем агент нужен · роль — функция, а не персона · задачи достаточно узкие для первого запуска · есть список «не делает» · понятен источник истины · tools описаны с правилами · есть правила памяти · approval для рискованных действий · понятный output · есть отчётность · проверяемые критерии качества · есть stop rule.
Три и более «нет» — роль не готова: сузить и уточнить.

## Красные флаги
- «Бизнес-агент», «помогай бизнесу расти», «действуй разумно».
- Tools: «все доступные».
- Пустой блок «не входит» — главная защита от опасной автономии отсутствует.
- Память = «помни всё».
- Отчёт = «Готово.» — это тупик, а не отчёт.

## Вопросы-провокации для R3 (генерируй варианты из них)
- Что агент никогда не должен обещать? (цена, срок, результат, интеграция, юридические гарантии)
- Какие данные он никогда не должен менять или удалять?
- Какие решения всегда принимает человек?
- Что он не отправляет наружу сам?
