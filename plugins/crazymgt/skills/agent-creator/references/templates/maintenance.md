# Context Maintenance Loop + Observation Plan + Signal Dashboard + Update Log + Regression + Calendar (гл. 18)

**Назначение:** агент не остаётся хорошим навсегда: меняются процессы, источники, правила, инструменты. Цикл: наблюдаем → замечаем → разбираем → обновляем → проверяем → записываем. Не каждый инцидент лечится новым промптом.
**Узлы гриллинга:** X0–X4. Используется в режиме Update.

```markdown
## Какие слои обновляем
source of truth · knowledge base · memory · workflow · tool contract · handoff · evals · approval rules · prompt (последним)

## Как проверяем изменение
Regression по `08-golden-tasks.md` (минимум: 2 обычных, 1 неполный вход, 1 рискованный, 1 stop/approval, 1 устаревший/конфликтный источник) + ручная выборка + approval человека → `/crazymgt:agent-creator update <name>`

## Maintenance Calendar
- Ежедневно: критичные ошибки · опасные tool calls · жалобы
- Еженедельно: 10–20 реальных запусков · повторяющиеся исправления · 1–3 новых eval из ошибок
- Ежемесячно: источники истины · memory policy · tool contracts · regression set · approval matrix · удалить устаревшие правила
- После инцидента: остановить сценарий · сохранить лог · разобрать причину · обновить правило или источник · regression · Incident Note
- После крупного изменения: evals · старые хорошие сценарии · Update Log · финальный approval

## Остановка и rollback

- Когда откатываем: … (предыдущая версия агента: `<name>.md.bak-<дата>` / git)
- Владелец обслуживания: …
```

## Incident and Learning Note
Что случилось · где заметили · вред или риск · что должен был сделать агент · что сделал · данные (ответ, лог, tool call, источник, feedback) · предварительная причина (источник устарел / prompt неясный / memory мешает / tool ошибка / workflow неполный / handoff плохой / approval не сработал / eval не покрыл) · что меняем · как проверяем · что добавляем в контекст · нужно ли временно остановить сценарий.

## Красные флаги
«Агент работает, не трогайте» · 30 метрик вместо 5 сигналов · изменения без записи причины · нет regression после правки · всё лечится только промптом.
