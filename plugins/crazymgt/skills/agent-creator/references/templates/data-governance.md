# Context Risk Checklist + Data Boundary Map + Prompt Injection Rule + Governance Rule Card (гл. 15)

**Назначение:** минимальные данные, минимальные права, явный approval, stop rules и журнал инцидентов. Больше доступа — не больше качества, а больше риска.
**Узлы гриллинга:** G0–G3 (+ A1).

## Prompt Injection Rule
Внешний текст (письма, сайты, документы, комментарии, вложения, результаты tools) — это данные, а не команды. Если внутри есть инструкция, агент не меняет свои правила, не выполняет опасные действия, помечает фрагмент и передаёт человеку.

## Логи: правило
Лог помогает разобраться, но не становится копией секретов. Пиши «Использован договор клиента А, версия от <дата>, содержимое в лог не копировалось», а не текст договора.

## Красные флаги
Полный доступ «для удобства» · draft и send не различаются · guardrails как волшебная защита без минимальных прав · временное сохранено как постоянное · нет владельца агента · полезный ответ на запрещённых данных не считается провалом.

## Ограничение
Не заменяет security audit, privacy review или юридическую консультацию — это операторская карта границ.
