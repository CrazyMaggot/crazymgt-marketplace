# Eval Checklist + Result Rubric + Escalation Rule + Failure Log (гл. 14)

**Назначение:** приёмка работы агента. Проверяем не только финальный текст, но и источники, tools, траекторию и границы approval. Агент без evals — работа без приёмки.
**Узлы гриллинга:** E1, E2, E4, F2.

## Шаблон `07-eval-checklist.md`

```markdown
# Eval Checklist — <агент>
Связано: 01, 02, 03, 04, 05, 06, 08

1. **Агентная задача:** …
2. **Роль агента:** …
3. **Хороший результат (3–5 признаков):**
4. **Провал / красные флаги (3–5):**
   - нарушена approval boundary — провал, даже если текст хороший
5. **Источники истины:** <что должно быть использовано>
6. **Проверка финального ответа:** формат, полнота, факты, ясность, следующий шаг
7. **Проверка источников:** правильные ли, нет ли догадок, отмечено ли «не найдено»
8. **Проверка tools:** что можно и нельзя было вызывать
9. **Проверка trajectory:** правильный ли порядок шагов, сработали ли stop rules
10. **Approval boundary:** что нельзя без человека
11. **Escalation Rule:** агент обязан остановиться и передать человеку, если… (≥3 условия)
12. **Grader:** правило/код — <что>; LLM-as-judge — <что>; человек — <что>
13. **Решение после проверки:** выпускать · исправить контекст · роль · источник · tool contract · остановить и передать человеку

## Result Rubric
| # | Критерий | Pass | Fail |
|---|---|---|---|
| 1 | Факты верны | | |
| 2 | Источник указан или учтён | | |
| 3 | Запрещённых обещаний нет | | |
| 4 | Формат соблюдён | | |
| 5 | Следующий шаг понятен | | |
| 6 | Риск эскалирован | | |
(5–7 критериев; 25 критериев никто не использует)
```

## Шаблон `failure-log.md`

```markdown
## <YYYY-MM-DD> — <test case>
- Что ожидали:
- Что агент сделал:
- Что провалено:
- Тип ошибки: задача | контекст | роль | tool contract | memory | рубрика | источник | handoff | approval
- Причина:
- Исправление: <файл Pack + правило>
- Новый тест: <да — какой | нет>
- Статус повторной проверки:
```

## Критерии качества
Проверяется траектория, а не только текст · есть описание провала · ясно, где правило, код, LLM-judge и человек · есть Failure Log · явное правило остановки.

## Красные флаги
Только лёгкие кейсы · оценка «на глаз» · рубрика на 25 пунктов · вера LLM-судье без калибровки (10 результатов: человек vs модель) · ошибки не записываются.
