# Domain Context Map + Business Process Map + Vocabulary + Decisions/Exceptions + Agent Fit (гл. 16)

**Назначение:** агент работает не в вакууме, а в конкретном домене. Если человек не может объяснить процесс на бумаге, агент не сможет стабильно выполнять его в реальности — он просто ускорит хаос.
**Узлы гриллинга:** P5, D1–D5.

## Критерии качества
Конкретный процесс, а не отдел · trigger/input/output есть · шаги без «обработать» и «улучшить» · роли названы · есть owner · термины объяснены · источники по порядку доверия · решения и исключения названы · разметка A/D/H/N · есть проверка.

## Красные флаги
«Агент продаж: помогай продавать, веди сделки» · нет владельца процесса · правила живут в голове одного сотрудника · «правильно» зависит от настроения руководителя · термины («пилот», «лид», «сделка») не определены.

## Где искать факты для вариантов
Регламенты, README, глоссарии, шаблоны документов, названия статусов в данных проекта. Из них собирай кандидаты терминов для D4.
